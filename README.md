# GymApp

Proyecto universitario de entrenamiento (React Native + Expo).

## Requisitos
- Node.js LTS (18 o 20)
- npm (o yarn/pnpm)
- Git (si vas a clonar el repo)
- Para movil: instalar Expo Go en el telefono
- Para emulador Android: Android Studio y SDK
- Para simulador iOS: macOS con Xcode

## Instalacion

npm install

## Ejecutar
npx expo start

Opciones para abrir la app:
- En movil: escanea el QR con Expo Go
- En Android emulador: presiona "a" en la consola

## Solucion rapida de problemas
- Limpiar cache:

npx expo start -c

- Si hay errores raros:
  - Borra node_modules y reinstala dependencias
  - Verifica version de Node
